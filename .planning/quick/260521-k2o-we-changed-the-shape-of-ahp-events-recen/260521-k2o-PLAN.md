# Quick Task 260521-k2o

## Description

Recent AHP event-shape changes make logs fail to load cleanly. During append, `EventStore` catches a subscriber exception and warns with `Cannot read properties of undefined (reading 'length')`, so the viewer loses rows even though ingest itself continues.

## Diagnosis

`EventStore` is only the warning boundary. The server `AppState` subscriber projects every appended event into an `EventRow`, and `projectRow()` computes `summary` through `summarizeEvent()`. In `packages/core/src/summary.ts`, known tool-action summaries still dereference legacy fields directly:

- `SessionToolCallDelta` reads `action.content.length`
- `SessionToolCallContentChanged` reads `action.content.length`

That is the strongest current match for the reported warning: a reshaped emitted action reaches row projection, summary generation reads a now-missing field, and the exception bubbles back to the `EventStore` subscriber guard. Treat the direct `.length` reads as the working hypothesis, then confirm them against the current canonical shape in `../agent-host-protocol` before changing production code. Do not patch around this in `EventStore`; the warning is a symptom, not the broken event-shape assumption.

## Tasks

1. Confirm the current canonical wire/action shape and encode the regression that reproduces the broken subscriber path.
   - Compare the affected tool-call action definitions and representative emitted JSON shape against `../agent-host-protocol`; if `packages/protocol` is stale, use the existing sync flow rather than hand-editing generated protocol definitions.
   - Add focused assertions in `packages/core/src/row-projection.test.ts` for the reshaped action payloads that currently make summary projection read an absent `.length` field.
   - Add an ingest-level regression in `packages/server/src/app-state.test.ts` that pushes a sanitized JSONL line for the same shape, verifies rows are appended, and verifies the `EventStore` subscriber warning path is not hit.

2. Fix summary generation at the root assumption, preserving useful row summaries for canonical reshaped events.
   - Update `packages/core/src/summary.ts` to summarize the canonical current tool-action payload shape without assuming `content` is always present in its former representation.
   - Keep known-action summaries typed and shape-aware; prefer the synced protocol contract or explicit narrow guards over broad `unknown` fallbacks. Existing legacy/unknown-action summarization should remain the fallback for truly non-canonical payloads, not the main fix.
   - If protocol sync changes generated files under `packages/protocol/src/`, include only the generated deltas required by the canonical shape shift and keep summary logic aligned with those types.

3. Run the focused verification gate for the affected projection and ingest surfaces.
   - `pnpm test -- packages/core/src/row-projection.test.ts packages/server/src/app-state.test.ts`
   - `pnpm typecheck`

## Done When

- The exact reshaped AHP action payload that used to trigger `Cannot read properties of undefined (reading 'length')` is captured in tests.
- Loading that payload through `AppState` appends rows without an `EventStore` subscriber warning.
- Timeline summaries remain meaningful for the current canonical tool-action shape rather than crashing or blanketing the issue with a generic store-level guard.
- Focused tests and typecheck pass.
