<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser/client query -> `/api/state-at` | Untrusted query strings select event index, log key, and optional resource. |
| AppState replay result -> JSON response | Log-derived reconstructed state leaves the server process only through local HTTP. |
| Active log lifecycle -> route requests | Route callers may hold stale `logKey` across log switches. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-08-02-01 | Tampering | `idx` query | mitigate | Validate with `/^(0|[1-9]\d*)$/`; reject partial numeric strings like `1abc`. |
| T-08-02-02 | Information Disclosure | State route response | mitigate | Metadata-only by default; full `state` only for selected `resourceKind` + `resourceUri`. |
| T-08-02-03 | Information Disclosure | File paths | mitigate | Return `logKey` and protocol resource URIs only; tests assert no absolute path leakage. |
| T-08-02-04 | Spoofing | Stale active log | mitigate | Optional `logKey` must match active session key or return `409 log-mismatch`. |
| T-08-02-05 | Denial of Service | Resource selector/query | mitigate | Strict query validation and no unbounded search; state computation remains bounded by AppState cache from 08-01. |
</threat_model>
