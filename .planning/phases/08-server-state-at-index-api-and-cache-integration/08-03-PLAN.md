<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Synthetic JSONL -> parser/AppState/replay | Test data simulates untrusted protocol logs without using private real logs. |
| SSE stream -> browser/client | Timeline transport must not leak replay state or file paths. |
| Log switch/rotation -> route cache | Active log changes invalidate stale cache assumptions and stale client log keys. |
| Large generated logs -> server memory/runtime | Tests must prove state lookup and SSE payloads remain bounded enough for local use. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-08-03-01 | Information Disclosure | Test fixtures | mitigate | Use synthetic in-test JSONL only; no real logs or absolute paths. |
| T-08-03-02 | Information Disclosure | SSE frames | mitigate | Assert SSE frame JSON excludes `resources`, `diagnostics`, `intents`, `cache`, and full replay `state`. |
| T-08-03-03 | Spoofing | Log switch route calls | mitigate | Test stale `logKey` returns `409 log-mismatch` after active log changes. |
| T-08-03-04 | Denial of Service | Large-log/SSE behavior | mitigate | Generated large-log test asserts SSE payload shape does not inflate with replay state. |
| T-08-03-05 | Tampering | Rotation lifecycle | mitigate | Cache reset tests confirm replacement logs start at index 0 with no stale replay hit. |
</threat_model>
