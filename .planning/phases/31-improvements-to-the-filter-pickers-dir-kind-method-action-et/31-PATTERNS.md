## Shared Patterns

### Checked Means Visible; Complete Set Means `options`

**Sources:** `FilterBar.tsx` lines 38-64 and `FacetPopover.tsx` lines 43-58, 163-214  
**Apply to:** `FacetPopover.tsx`, `FilterBar.tsx`, `FilterBar.test.tsx`, both Phase 25/31 E2E specs

- Store arrays remain hidden values.
- `selected` remains the complete currently visible values.
- Bulk label and action derive from complete `options`, even with a query or the 100-row rendered cap.
- Newly discovered non-hidden values remain visible.

### Deterministic Display Projection

**Source:** `FilterBar.tsx` lines 27-36, 86-92  
**Apply to:** all seven categorical facet pickers and ordering tests

Sort once after visible labels are formatted. Use case-insensitive visible label first and raw value as deterministic tie-breaker. Counts and first-arrival order never participate.

### Local Geometry Fixes

**Source:** `SearchPopover.tsx` lines 62-82  
**Apply to:** FacetPopover query input and GroupToggleChip option labels only

Use inline `boxSizing: "border-box"` beside existing full-width styles. Do not touch `global.css`, tokens, or add JavaScript measurement.

### Native Controls and Semantic Tokens

**Sources:** `FacetPopover.tsx` lines 60-240; `GroupToggleChip.tsx` lines 48-98  
**Apply to:** all picker product changes

Keep native checkbox/radio/button/input controls, existing focus handlers, semantic token colors, compact dimensions, and raised-surface styles. Do not add dependencies, icons, raw colors, ARIA role changes, or Escape behavior.

### Component Test Ownership

**Source:** `FilterBar.test.tsx` lines 17-68, 220-354  
**Apply to:** all Phase 31 component regressions

Keep FacetPopover and GroupToggleChip behavior in the existing FilterBar integration test file. Use `makeRow`, direct `useAppStore.setState`, role/name queries, `fireEvent`, and direct store/style assertions.

### Fixture-Only Browser Evidence

**Sources:** `e2e/phase25.spec.ts` lines 1-92, 97-208; `.github/copilot-instructions.md` lines 50-52  
**Apply to:** `e2e/phase31.spec.ts` and `screenshots/phase31/*.png`
