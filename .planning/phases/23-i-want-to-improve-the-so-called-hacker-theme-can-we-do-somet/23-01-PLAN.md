<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Hacker paint-space displacement -> DOM hit-testing | SVG filters move rendered pixels without moving browser hit areas. |
| Filtered display wrapper -> responsive fixed overlays | A non-root filtered surface can alter containing-block behavior for drawer/backdrop/picker surfaces. |
| CRT filter definition -> extension CSP/local-only runtime | The effect definition must stay same-document and bundled rather than fetching runtime assets. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-01-01 | D | `crt-display-surface` paint warp and UI controls | mitigate | Keep warp scale bounded at `18`, then execute ordinary-click Playwright checks for Theme picker, timeline row, search, picker dialog, and drawer close. |
| T-23-01-02 | T | `.detail-drawer-backdrop` under filtered surface | mitigate | Browser-test the 1366x768 responsive drawer backdrop bounding box and dismiss flow with the actual chosen wrapper. |
| T-23-01-03 | I | SVG filter resources | mitigate | Define `ahp-crt-warp` inline in React with no remote URL, texture download, or runtime outbound fetch. |
</threat_model>
