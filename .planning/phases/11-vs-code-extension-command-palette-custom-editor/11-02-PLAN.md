## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| UI components -> transport client | UI calls a runtime-provided client that may be browser HTTP/SSE or VS Code webview messaging. |
| Browser client -> loopback server | Standalone browser mode continues to call same-origin `/api/*` endpoints. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-02-01 | Tampering | `client.ts` | mitigate | Keep typed request/response contracts; do not accept untyped `unknown` responses past the transport boundary. |
| T-11-02-02 | Information Disclosure | UI transport | mitigate | Preserve basename/logKey-only metadata in UI-visible contracts; do not add absolute path fields to shared UI types. |
| T-11-02-03 | Denial of Service | stream replacement | mitigate | Preserve explicit `close()` handling when replacing streams to avoid duplicate listeners. |
</threat_model>
