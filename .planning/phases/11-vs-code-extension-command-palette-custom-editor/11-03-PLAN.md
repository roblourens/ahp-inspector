<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Webview -> extension host | Webview sends JSON messages requesting local log operations. |
| Extension host -> webview | Extension host sends sanitized viewer data and stream frames into webview JavaScript. |
| Extension host -> filesystem | Extension host opens and watches local files selected by active editor or discovery. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-03-01 | Spoofing | `messageProtocol.ts` | mitigate | Require known discriminated message kinds and request IDs; ignore unknown messages. |
| T-11-03-02 | Tampering | `viewerSession.ts` | mitigate | Validate request payload types before using them; map invalid input to typed error responses. |
| T-11-03-03 | Information Disclosure | `viewerSession.ts` | mitigate | Keep absolute paths out of metadata/stream responses; only extension host keeps selected file paths. |
| T-11-03-04 | Denial of Service | `webview-client.ts` | mitigate | Remove message listeners and close stream handles on disposal; avoid unbounded pending request maps. |
</threat_model>
