<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| VS Code command -> extension host | User-triggered command can observe active editor metadata. |
| Extension host -> webview HTML | Extension host injects local asset URIs and initial log metadata into webview content. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01-01 | Information Disclosure | `activeLog.ts` | mitigate | Return filesystem path only inside extension host flow; webview-visible metadata must use basename/logKey in Plan 03 bridge tasks. |
| T-11-01-02 | Tampering | `webviewHtml.ts` | mitigate | Use nonce-bearing CSP and `webview.asWebviewUri`; do not interpolate unescaped user-controlled file paths into HTML. |
| T-11-01-03 | Elevation of Privilege | `extension.ts` | mitigate | Keep command registration narrow; do not execute shell commands or open arbitrary external URLs. |
</threat_model>
