<objective>
Make search keyboard-accessible via cmd+f / ctrl+f, focus the search input whenever the popover is opened (keyboard shortcut OR trigger click), and reduce the SearchTrigger button to an icon only.

Purpose: The user wants the standard find shortcut (cmd+f) to drive in-app search, clicking the search button should put the cursor straight in the box, and the redundant "Search" text label adds visual noise next to a self-explanatory icon.
Output: Updated FilterBar keyboard + click handling, icon-only SearchTrigger, and matching test updates.
</objective>
