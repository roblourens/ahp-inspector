## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| sibling repo → generated package | Local sync script reads from `../agent-host-protocol/types` and writes committed generated source. |
| generated fixtures → test suite | Copied JSON fixtures enter this repo and must remain synthetic reducer fixtures, not real user logs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Tampering | `scripts/sync-agent-host-protocol.ts` | mitigate | Resolve source/destination with `path.resolve`, require each source path to stay under `../agent-host-protocol/types`, copy only `PROTOCOL_FILES`, and fail if required sources are missing. Verify with `grep -q 'const PROTOCOL_FILES' scripts/sync-agent-host-protocol.ts` and `pnpm sync:ahp`. |
| T-06-02 | Tampering | `packages/protocol/src/*`, `.ahp-version` | mitigate | Generated files carry `DO NOT EDIT` banner; `.ahp-version` and `source-info.ts` are generated from `git rev-parse --short HEAD`; Plan 03 adds tests that assert the commit is present and test-visible. |
| T-06-05 | Information Disclosure | `packages/protocol/test-cases/reducers` | mitigate | Script copies only `*.json` under `types/test-cases/reducers`; it never copies `.jsonl`, `.log`, or arbitrary real log paths. Verify no generated fixture path has `.jsonl` or `.log`. |
</threat_model>
