<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user-entered row filter text -> browser row projection scan | Arbitrary text drives local filtering over potentially large visible-row arrays. |
| server-projected EventRow -> UI predicate | Log-derived display strings are untrusted content used only as plain text. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25-01 | D | `applyFacets` / `useFilteredRows` | mitigate | Cap row-filter query processing to 256 characters, use literal `includes`, and retain deferred filter computation. |
| T-25-02 | T/I | row-text predicate | mitigate | Match plain projection strings only; no regex construction, HTML injection, raw-event fetch, or outbound dependency. |
</threat_model>
