<objective>
Make Escape close the find widget without clearing the row filter box, and make
Escape never clear any filter.

Purpose: The app has TWO document-level Escape listeners. `SearchPopover`
(mounted only while the find widget is open) handles Escape by calling
`onClose()` — good. But `TimelineRegion` also installs a global `keydown`
handler whose Escape branch is:

```ts
if (searchQuery) { setSearchQuery(""); clearSearchResults(); }
else if (!isFiltersEmpty(filters)) { clearFilters(); }   // ← wipes rowText + facets
else { clear(); }                                        // ← clears selection
```

So when the user has text in the row filter box (`filters.rowText`), opens the
find widget with Cmd+F, and presses Escape, BOTH handlers fire: the popover
closes AND — because `searchQuery` is empty — the global handler falls into the
`clearFilters()` branch and erases the filter. Even with no find widget, Escape
clears all filters. The user wants Escape to never clear a filter, and a single
Escape to just dismiss the find widget.

Output: A shared `searchPopoverOpen` store flag the global handler can read, an
Escape handler that (1) bails when the find widget is open and (2) no longer has
a `clearFilters()` branch, plus unit + e2e coverage of the Escape ladder.
</objective>

<task name="Add a shared searchPopoverOpen flag and stop Escape from clearing filters">

**1. Store — add the shared find-widget flag.**
In packages/ui/src/state/store.ts:
- Add to the state interface: `searchPopoverOpen: boolean;` and
  `setSearchPopoverOpen(open: boolean): void;` (place them next to the other
  Phase 3 search fields).
- Add the initial value `searchPopoverOpen: false` and the action
  `setSearchPopoverOpen: (open) => set({ searchPopoverOpen: open })` in the store
  implementation.

**2. FilterBar — route the find widget through the store.**
In packages/ui/src/components/filters/FilterBar.tsx:
- Replace the local `useState` for `isSearchPopoverOpen` with the store value:
  `const isSearchPopoverOpen = useAppStore((s) => s.searchPopoverOpen);` and
  `const setSearchPopoverOpen = useAppStore((s) => s.setSearchPopoverOpen);`.
- `openSearch()` calls `setSearchPopoverOpen(true)` (keep the `setTimeout`
  focus-on-mount behavior).
- The SearchTrigger `onClick` toggle and `<SearchPopover onClose={...}>` close
  paths call `setSearchPopoverOpen(false)`.
- Keep the existing `"/"` and Cmd+F / Ctrl+F open shortcut and its
  `e.preventDefault()` (native-find suppression) unchanged otherwise.

**3. TimelineRegion — bail when the find widget is open, and remove the clearFilters branch.**
In packages/ui/src/components/timeline/TimelineRegion.tsx, change the Escape
branch to:
```ts
if (e.key === "Escape") {
  // Find widget open → let SearchPopover.onClose dismiss it; do nothing else.
  if (useAppStore.getState().searchPopoverOpen) return;
  if (searchQuery) {
    setSearchQuery("");
    clearSearchResults();
  } else {
    clear();
  }
  return;
}
```
Remove the `else if (!isFiltersEmpty(filters)) { clearFilters(); }` branch
entirely so Escape can never clear a filter. If `clearFilters`, `filters`, and
the `isFiltersEmpty` import become unused after this change, remove those unused
bindings/imports to keep the file clean (leave them only if still referenced
elsewhere in the file).

Do NOT change SearchPopover's own Escape→onClose handler — it stays the
authoritative "close the find widget" path; with the store flag wired,
`onClose` now also flips `searchPopoverOpen` to false via FilterBar.
</task>
