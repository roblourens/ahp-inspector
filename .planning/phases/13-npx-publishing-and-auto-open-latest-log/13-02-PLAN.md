<interfaces>
<!-- Existing analog: the extension already does this exact dance. Mirror its approach. -->

`packages/extension/scripts/copy-ui-dist.cjs` copies `packages/ui/dist/*` to `packages/extension/ui-dist/` and renames the hashed `index-*.{js,css}` to stable `main.{js,css}`. The CLI does NOT need the rename step — `locateUiDist()` in `packages/cli/src/index.ts` looks for `index.html` and the UI loads its own hashed assets via the HTML.

CLI runtime asset lookup (already in code, do NOT change the algorithm):
```typescript
// packages/cli/src/index.ts — locateUiDist() candidates:
resolvePath(workspacePackagesDir, "ui", "dist"),     // monorepo dev
resolvePath(cliPackageDir, "ui", "dist"),            // packaged: cli/ui/dist
resolvePath(workspaceRootDir, "packages", "ui", "dist"),  // monorepo fallback
```

The published tarball will lay out as `node_modules/ahp-inspector/{dist,ui-dist,package.json}`. We need to add a 4th candidate to `locateUiDist()`: `resolvePath(cliPackageDir, "ui-dist")` (NOT `ui/dist`) so the packaged layout is found.
</interfaces>
</context>
