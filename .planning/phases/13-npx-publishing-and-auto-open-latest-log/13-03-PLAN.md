  <action>
Create `scripts/release.sh` (executable, `#!/usr/bin/env bash`, `set -euo pipefail`).

Usage:
```
scripts/release.sh [--dry-run] [<version>]
```

Behavior:
1. Parse args: `--dry-run` is optional; positional `<version>` is optional. If `<version>` is omitted, read the current version from `packages/cli/package.json` and prompt: "Release ahp-inspector@${CURRENT}? [y/N]". Abort on non-y.
2. If `<version>` is given, validate it as semver (`^[0-9]+\.[0-9]+\.[0-9]+(-[a-z0-9.]+)?$`). Bump via `pnpm --filter ahp-inspector version "$VERSION" --no-git-tag-version` (workspace-aware; does not touch git). Print the new version.
3. Run pre-flight (always, including `--dry-run`):
   ```bash
   git diff --quiet || { echo "Working tree dirty — commit or stash first."; exit 1; }
   pnpm install --frozen-lockfile
   pnpm typecheck
   pnpm test
   pnpm -F @ahp-inspector/ui build
   pnpm -F ahp-inspector build
   ```
4. Smoke test the tarball (always):
   ```bash
   cd packages/cli
   npm pack
   TARBALL="ahp-inspector-${VERSION}.tgz"
   TMP=$(mktemp -d)
   ( cd "$TMP" && npm init -y > /dev/null && npm i "$PWD/$TARBALL" >/dev/null && npx ahp-inspector --version | grep -q "^${VERSION}$" )
   echo "Tarball smoke test passed."
   ```
5. **Publish step**:
   - If `--dry-run`: print `Dry run — would now run: npm publish --access public` and exit 0. Leave the tarball in place for inspection.
   - Otherwise: `npm publish --access public` (run inside `packages/cli`). After success, `git tag "v${VERSION}"` and print: `Published ahp-inspector@${VERSION}. Push the tag with: git push origin v${VERSION}`.
6. Cleanup: remove the tarball (`rm "$TARBALL"`) on success and on failure (use a trap).

Make executable: `chmod +x scripts/release.sh` (the executor must run this after creating the file).

Sanity-check the script structure (no real publish):
```bash
bash -n scripts/release.sh  # syntax check
```

<task type="auto">
  <name>Task 2: Add manual workflow_dispatch publish workflow</name>
  <files>.github/workflows/publish.yml</files>
  <action>
Create `.github/workflows/publish.yml` — a manual `workflow_dispatch` workflow that mirrors `scripts/release.sh` end-to-end. Tag-push triggers are intentionally NOT used (per CONTEXT open question — manual trigger is the safer default).

```yaml
name: Publish ahp-inspector to npm

on:
  workflow_dispatch:
    inputs:
      version:
        description: "Version to publish (e.g. 0.1.0). Leave blank to use packages/cli/package.json as-is."
        required: false
        type: string
      dry_run:
        description: "Dry run (skip npm publish, run everything else)"
        required: false
        type: boolean
        default: true

jobs:
  publish:
    runs-on: ubuntu-latest
    permissions:
      contents: read
      id-token: write  # for npm provenance
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
        with: { version: 9 }
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: pnpm
          registry-url: "https://registry.npmjs.org"
      - run: pnpm install --frozen-lockfile
      - run: pnpm typecheck
      - run: pnpm test
      - run: pnpm -F @ahp-inspector/ui build
      - run: pnpm -F ahp-inspector build
      - name: Bump version (if requested)
        if: inputs.version != ''
        run: pnpm --filter ahp-inspector version "${{ inputs.version }}" --no-git-tag-version
      - name: Pack and smoke test
        working-directory: packages/cli
        run: |
          npm pack
          TARBALL=$(ls ahp-inspector-*.tgz | head -1)
          TMP=$(mktemp -d)
          ( cd "$TMP" && npm init -y > /dev/null && npm i "$PWD/$TARBALL" )
          echo "Smoke test passed."
      - name: Publish to npm
        if: inputs.dry_run == false
        working-directory: packages/cli
        env:
          NODE_AUTH_TOKEN: ${{ secrets.NPM_TOKEN }}
        run: npm publish --access public --provenance
      - name: Dry-run notice
        if: inputs.dry_run == true
        run: echo "Dry run — npm publish skipped."
```

Notes:
- Default `dry_run: true` so accidental triggers don't publish.
- `provenance: true` requires `id-token: write` permission and GH Actions OIDC; this is the npm-recommended secure publish path.
- The `NPM_TOKEN` secret must be added by Rob in the repo settings before the first real publish — not in scope for this plan.

```markdown
## Quickstart

Open the most recent VS Code Agent Host log in the browser:

```bash
npx ahp-inspector
```

This downloads `ahp-inspector` to npx's cache, starts a local HTTP server on `127.0.0.1`, opens your default browser, and streams the most-recently-modified AHP JSONL log it can find under your standard VS Code log roots.

Open a specific file:
```bash
npx ahp-inspector path/to/agent-host.jsonl
```

Flags:
- `--port <n>` — choose a specific port (default: 5173; `0` for ephemeral).
- `--no-open` — start the server but don't auto-open the browser.

### Auto-discovery rule

When invoked with no path argument, `ahp-inspector`:
1. Scans the standard VS Code log roots (Code, Code - Insiders, OSS dev) up to a bounded time/stat budget.
2. Skips empty (0-byte) files.
3. For each candidate (newest mtime first), probes the first line to verify it parses as an AHP event.
4. Opens the first match. If none qualify, the browser opens to the discovery picker so you can browse manually — no error.

### Privacy posture

`ahp-inspector` is local-only by design:
- Server binds to `127.0.0.1` (loopback only).
- No telemetry, no update checks, no outbound network calls.
- Log files are read locally; nothing is uploaded anywhere.
```
