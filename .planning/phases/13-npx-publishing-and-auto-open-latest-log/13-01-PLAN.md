  <action>
Create `packages/host-node/src/find-latest-ahp-log.ts` exporting:

```typescript
export async function findLatestAhpLog(): Promise<string | null>;
```

Implementation:
1. Call the existing `discoverVsCodeLogs()` (same module — internal import from `./discovery.js`) to enumerate candidates. The candidates already have `mtimeMs`, `sizeBytes`, and confidence tier.
2. **discoverVsCodeLogs returns LogCandidate without an absolute path.** Add a parallel internal helper or extend the discovery walker to return a path-bearing variant. Simplest: inside this new module, run a private walk that mirrors `discoverVsCodeLogs` but yields `{ absPath, mtimeMs, sizeBytes }` triples. Reuse the same `defaultRoots()` and filename regex (`FILENAME_RE_AHP_JSONL`, `FILENAME_RE_AHP_NAMED_JSONL`) by exporting them from `discovery.ts` (add `export` keyword to the two regexes and the `defaultRoots` function). Apply the same bounded depth (3), time budget (1500ms), and max stats (5000) caps as discovery.
3. Filter out `sizeBytes === 0`.
4. Sort remaining candidates by `mtimeMs` descending.
5. For each candidate (in mtime-desc order, capped at first 10 to bound the probe cost), open the file with `fs.promises.open()`, read up to the first 64 KiB (enough to find a complete first line; AHP events are typically &lt;4 KiB), close it, find the first non-empty line by splitting on `\n`, and probe AHP shape:
   - Use `parseLine(line, 0, Buffer.byteLength(line))` from `@ahp-inspector/parser`. If `.error` is set, reject this candidate.
   - If `.value` is truthy, attempt `normalize(parsedLine.value, { lineNumber: 1, source: "discovery-probe" })` from `@ahp-inspector/parser`. If it throws or returns falsy, reject this candidate. Wrap in try/catch — normalize throws on non-AHP shapes.
   - If both succeed, return the absolute path.
6. If no candidate passes the probe, return `null`.

Add to `packages/host-node/src/index.ts`:
```typescript
export { findLatestAhpLog } from "./find-latest-ahp-log.js";
```

Tests in `packages/host-node/src/find-latest-ahp-log.test.ts` (vitest):
- **newest-mtime selection**: write 3 valid AHP-shape JSONL fixtures into a tmpdir; mock or override `defaultRoots()` to point to the tmpdir; assert returned path matches the newest one.
- **0-byte filter**: include a 0-byte file with a newer mtime than valid candidates; assert it's skipped.
- **AHP-shape probe rejects unrelated jsonl**: include a file matching the AHP filename regex but containing `{"foo":"bar"}\n` (won't normalize); assert it's skipped.
- **null when none match**: empty tmpdir → returns `null`.
- **does not throw on unreadable file**: a file with mode 0 (chmod 000) — should be skipped, not thrown.

Use `node:fs/promises` `mkdtemp` + `os.tmpdir()` for fixture root. Make the discovery roots overridable via an injected option on `findLatestAhpLog({ rootsOverride: Root[] })` (test-only param; default uses real roots) — this is the cleanest way to make the tests hermetic without monkey-patching. Type the option as `readonly Root[]` where `Root = { origin: string; dir: string }`. Re-export the type from discovery.ts.
