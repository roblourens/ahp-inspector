## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Timeline vertical row padding, icon gaps, inline padding |
| sm | 8px | Timeline horizontal cell padding, compact element spacing |
| md | 16px | Default element spacing |
| lg | 24px | Timeline row height, group/header height, section padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions: existing `--space-3: 12px` remains allowed for legacy component gaps. Phase 33 timeline rows must use `24px` height; do not introduce a density toggle.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Timeline row cells / prefix | 12px | 400 | 16px |
| Timeline event leaf / badges | 12px | 600 | 16px |
| Body / detail text | 14px | 400 | 1.5 |
| Heading | 16px | 600 | 1.2 |

Rules:
- Use only weights `400` and `600`.
- Apply the 12px row size only to timeline rows and timeline headers; do not globally shrink filter controls, detail pane, picker rows, or body text.
- Preserve monospace rendering for `.ts`, `.latency`, `.id`, `.method`, and `.preview`.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--color-bg` - dark `#0e1116`, light `#f7f8fb`, hacker `#020704` | App background and timeline viewport |
| Secondary (30%) | `--color-surface`, `--color-surface-raised` | Header row, grouped rows, panels, cards |
| Accent (10%) | `--color-accent` - dark `#7aa2f7`, light `#245fc7`, hacker `#39ff88` | Focus ring, selected row rail/background mix, existing active controls |
| Destructive | `--color-destructive` | Parse errors, auth failures, error status only |

Accent reserved for: selected row rail, selected row background mix, focus outline, existing active filter/search controls, and existing scroll-to-bottom control. Do not use accent for event-name prefix styling.

Additional Phase 33 semantic token:
- Add `--color-event-name-prefix` in dark, light, and hacker theme blocks.
- Value must be subtly muted but readable: closer to `--color-text-muted` than `--color-text-subtle`.
- Recommended definition: `color-mix(in srgb, var(--color-text-muted) 70%, var(--color-text) 30%)`.
- Event-name leaf remains `--color-text`.

## Interaction Contract

- Primary screen focal point: the selected timeline row remains the main visual anchor, with the event-name leaf as the highest-emphasis text inside each row.
- Timeline density target: reduce timeline event and parse-error rows from `28px` to `24px`.
- Keep group headers and column header at `24px`.
- Update virtualizer estimates, rendered row style height, parse-error rows, and latency cell height together.
- Keep row click, keyboard selection, tail-follow, search navigation, pair highlighting, grouping collapse, and scroll-to-bottom behavior unchanged.
- Event-name hierarchy:
  - For `foo/bar`, render `foo/` using `--color-event-name-prefix` and `bar` using normal event-name color/weight.
  - For deeper names, split at the last slash: `foo/bar/baz` -> prefix `foo/bar/`, leaf `baz`.
  - Do not split labels with no slash, leading slash only, or trailing slash only.
  - Render as React text spans only; never use `dangerouslySetInnerHTML`.
  - Preserve existing accessible row label/title as the full unsplit event name.
  - Preserve search highlighting across both prefix and leaf text.
