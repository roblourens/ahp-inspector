## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| search query -> rendered row labels | User-provided search text influences highlighting in row summaries. |
| match navigation -> selection state | Server-provided match indexes influence selected timeline row. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-02-01 | I | EventRow.tsx | mitigate | Continue using React text/mark nodes for highlighting; never use `dangerouslySetInnerHTML`. |
| T-12-02-02 | T | TimelineRegion.tsx | mitigate | Navigation must ignore match indexes not present in current rows or facet-visible rows. |
| T-12-02-03 | D | TimelineList.tsx | mitigate | Preserve virtualization; do not render offscreen match markers as full DOM rows. |
</threat_model>
