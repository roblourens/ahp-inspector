**Step 2 — Implement `useDropZone`:**

Create `packages/ui/src/components/drop/useDropZone.ts` exporting:
```typescript
import type { DropOverlayState } from './DropOverlay.js';
export interface UseDropZoneArgs {
  hasActiveLog: boolean;
  onOpenPath: (path: string) => Promise<void>;
}
export interface UseDropZoneResult {
  overlayState: DropOverlayState;
  toast: { basename: string; ignoredCount: number } | null;
  dismissError: () => void;
  dismissToast: () => void;
}
export function useDropZone(args: UseDropZoneArgs): UseDropZoneResult;
```

State machine (drives `DropOverlayState`):
- Initial: `{ kind: 'idle' }`.
- On `window.dragenter` carrying files (test: `event.dataTransfer?.types.includes('Files')`): `event.preventDefault()`, transition to `{ kind: 'armed', replacing: hasActiveLog }`.
  - **Use a depth counter** (initialized to 0; increment on `dragenter`, decrement on `dragleave`) to handle nested children correctly. Disarm only when the counter reaches 0 OR `event.relatedTarget == null` (per UI-SPEC §Interaction States: dragleave only disarms at the document edge).
- On `window.dragover`: `event.preventDefault()` always, even in error/idle (so the browser does not show the "denied" cursor or navigate). Do not change state.
- On `window.dragleave` with depth back to 0 (or `relatedTarget == null`): transition to `{ kind: 'idle' }` IF current state is armed/armed-replacing. If state is `error`, leave it alone — the user must dismiss explicitly.
- On `window.drop`: `event.preventDefault()`, reset the depth counter. Then:
  1. Read `event.dataTransfer`. If null, transition to error state with the locked "no file path" copy and stop.
  2. Call `parseDroppedUri(event.dataTransfer)`.
  3. If result is `{ kind: 'error', code: 'no-uri' }`: set state to `{ kind: 'error', message: NO_FILE_COPY }` where `NO_FILE_COPY` is the locked "That drop didn't include a file path. Try dragging from Finder or VS Code's file tree, or paste a path in the picker below." string.
  4. If result is `{ kind: 'error', code: 'not-jsonl' }`: set state to `{ kind: 'error', message: WRONG_EXT_COPY }` where `WRONG_EXT_COPY` is the locked "Only .jsonl files are supported. Drop the raw AHP log file." string.
  5. If result is `{ kind: 'ok', path, ignoredCount }`:
     - Compute `basename = path.split('/').pop() ?? path` (POSIX-only; Phase 17 is standalone web only — D-01).
     - Transition state to `{ kind: 'idle' }` immediately (success is silent in the overlay per UI-SPEC §Interaction States: `success-transient`).
     - Call `await args.onOpenPath(path)` inside a try/catch.
     - On success, if `ignoredCount > 0`, set the toast state to `{ basename, ignoredCount }`. Otherwise leave toast null.
     - On `SessionOpenError` (caught), look up `ERROR_COPY[err.code] ?? FALLBACK_ERROR` from the shared module and set overlay state to `{ kind: 'error', message: that_copy }`. Do NOT include `path` or `basename` in the error message — only the locked copy. (T-17-03-02 below.)
- `dismissError`: set state to `{ kind: 'idle' }`. (Caller wires this to `<DropOverlay onDismiss={...} />`.)
- `dismissToast`: set toast to `null`.

Locked copy constants (file-local consts at the top of `useDropZone.ts`):
```typescript
const NO_FILE_COPY =
  "That drop didn't include a file path. Try dragging from Finder or VS Code's file tree, or paste a path in the picker below.";
const WRONG_EXT_COPY =
  "Only .jsonl files are supported. Drop the raw AHP log file.";
```
These match the UI-SPEC "Copywriting Contract" verbatim.

Implementation notes:
- Use `useRef` for the depth counter (mutating it must not trigger re-render).
- Use `useEffect` keyed on `[hasActiveLog, onOpenPath]` to attach/detach listeners. The handler closures must read the current depth/state from refs to avoid stale-closure bugs.
- All listeners use `{ capture: false }` (default). Do NOT use `{ passive: true }` — we need `preventDefault()` to work.
- No `any`. Type the event handlers as `(e: DragEvent) => void`.
- The hook must be SSR-safe — guard window access with `typeof window === 'undefined'` and bail early in the effect (matches the existing pattern in `useIsDetailDesktop`).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser drag source → useDropZone | `text/uri-list` is attacker-controlled (page running in the browser can be tricked into receiving a hostile drag). |
| useDropZone → POST /api/sessions/open | The decoded path crosses to the local Node server (already audited in Phase 11/15). |
| server error response → DropOverlay | The server returns only `{ code }` (T-04-03-02 — never the original path); the overlay must keep that posture. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-03-01 | Information disclosure | useDropZone error mapping | mitigate | Error messages come from the shared `ERROR_COPY` table by `code` only. The hook never concatenates `path`, `basename`, or any URL into the overlay message. Tested in useDropZone.test.tsx case 8. |
| T-17-03-02 | Information disclosure | MultiFileToast usage | mitigate | The hook computes `basename = path.split('/').pop()` before constructing the toast prop. The absolute path is never passed to the component. Tested in case 5. |
| T-17-03-03 | Tampering (path traversal) | useDropZone → openSessionByPath | accept | Path validation is performed server-side by `packages/host-node/src/host-adapter.ts` (regular file + readable check). The client cannot bypass this; the worst a hostile drag can achieve is a server 4xx response, which surfaces as the standard ERROR_COPY message. |
| T-17-03-04 | Denial of service | useDropZone (rapid drag events) | accept | The state machine is debounced by React's render cycle; rapid drag events change a ref/state but do not spawn fetches. The fetch only fires on `drop`, and the existing rate-limit middleware on `POST /api/sessions/open` handles flooding. |
| T-17-03-05 | Browser navigation hijack | useDropZone listeners | mitigate | All four DnD events (`dragenter`/`dragover`/`dragleave`/`drop`) call `event.preventDefault()` to suppress the browser's default "open file" navigation. Tested implicitly: cases 1 and 4 would fail if the browser navigated away from the page. |
</threat_model>
