- The module-level `replaceLogStream()` function MUST move INSIDE the `AppShell` component because it now needs access to `client`. Refactor it to a `useCallback` defined inside the component:
  ```typescript
  const client = useAhpViewerClient();
  const replaceLogStream = useCallback((): LogStreamHandle => {
    const previous = typeof window !== "undefined" ? window.__ahpStream : undefined;
    previous?.close();
    const handle = client.connectLogStream();
    if (typeof window !== "undefined") window.__ahpStream = handle;
    return handle;
  }, [client]);
  ```
- Replace every call site:
  - `await fetchCandidates()` → `await client.fetchCandidates()`
  - `await openSessionByCandidate(id)` → `await client.openSessionByCandidate(id)`
  - `await openSessionByPath(path)` → `await client.openSessionByPath(path)`
  - `connectLogStream()` (line ~59) → `client.connectLogStream()` (now lives inside the `replaceLogStream` `useCallback`)
- Any `useCallback`/`useEffect` that previously closed over the deleted module functions or the old `replaceLogStream` must now list `client` and/or the new `replaceLogStream` in its dependency array. The existing dependency arrays around the picker handlers, retry handler, and last-open recovery effect must be updated.
- Confirm `window.__ahpStream` typing is unchanged (it already accepts `{ close(): void }`).
