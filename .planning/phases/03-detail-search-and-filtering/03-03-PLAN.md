**`SearchInput.tsx`** — controlled `<input type="text">` with:
- `placeholder="Search method, id, session, payload…"`
- lucide `Search` icon (16px) as left adornment
- lucide `X` icon (14px) as clear button when `value.length > 0`
- `text-row` font (13px mono); full-width but min 280px, max 480px
- dispatches `setSearchQuery` on change
- Props: `{ value: string; onChange(q: string): void; onClear(): void }`

**`FacetChip.tsx`** — a button that renders a facet selector chip:
- Label: `"{label} {count>0 ? '· ' + count : ''} ▾"` (count = active selection count)
- Background `--color-chip-bg`, border `1px solid var(--color-chip-border)`, border-radius 6px
- When popover is open: `--color-chip-bg-active`
- Props: `{ label: string; activeCount: number; isOpen: boolean; isDisabled: boolean; onClick(): void }`

**`FacetPopover.tsx`** — `<div role="listbox">` positioned under the chip:
- Each option is a `<label>` wrapping `<input type="checkbox">` + `<span>{option}</span>` + `<span>{count}</span>`
- Closes on click-outside (attach a `mousedown` listener to document on mount)
- `z-index: 200`
- Optional `searchable` prop: renders a filter-within-list `<input type="text">` (for method, session, turn facets)
- Props: `{ options: Array<{ value: string; label: string; count: number }>; selected: string[]; onChange(values: string[]): void; onClose(): void; searchable?: boolean }`

**`TimeRangePopover.tsx`** — two `<input type="datetime-local">` for from/to:
- Labels: "From" / "To"
- `[Apply range]` button dispatches `patchFilter("timeFrom", ...)` + `patchFilter("timeTo", ...)`
- `[Clear selection]` button clears both
- Props: `{ from: number | null; to: number | null; onApply(from: number|null, to: number|null): void; onClose(): void }`

**`GroupToggleChip.tsx`** — styled identically to `FacetChip` but always visible:
- Label: `"Group: {value} ▾"` where value is "None" | "Session" | "Session + Turn"
- Opens a popover with three radio-button options
- On selection, dispatches `setGrouping`; when switching away from "none", resets scroll to top
- Props: `{ value: GroupingMode; onChange(mode: GroupingMode): void }`

**`ResultCounter.tsx`** — display-only span:
- When `visible === total`: `"{total} events"` in `--color-text-muted`
- When `visible !== total`: `"{visible}/{total} events"` in `--color-text-muted`
- When `visible === 0`: render `"0/{total}"` in `--color-warning`
- `font-variant-numeric: tabular-nums`
- Props: `{ visible: number; total: number }`

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User typing in SearchInput → store.searchQuery | Free text; used for server-side substring search (capped at 256 in server route) |
| FacetPopover option click → FilterState | Option values come from EventRow fields (already normalized) — no arbitrary injection |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-03-01 | Tampering (XSS) | FacetPopover option labels | accept | Option values are EventRow field values (method, sessionId, etc.) rendered as React text children — auto-escaped; normalizer already stripped HTML |
| T-03-03-02 | DoS (UI freeze) | FacetPopover rendering 10k sessions | mitigate | SearchInput inside FacetPopover (`searchable={true}`) filters list before render; cap at 100 visible options with "…and N more" footer |
| T-03-03-03 | Accessibility | FilterBar keyboard navigation | mitigate | FacetChip is a `<button>`; FacetPopover items are `<input type="checkbox">` with `<label>`; GroupToggleChip uses `<button role="radio">` pattern — standard a11y |
</threat_model>
