<objective>
Replace the generic `summarizeValue(params)` fallback in the notification branches of `eventSummaryOf` with shape-aware extraction for the most common AHP notification payloads.

Purpose: Notification rows currently show pseudo-JSON (`{params:{type:..., state:...}}`-ish) instead of the human-readable state/message embedded in the payload.
Output: Tighter, more useful single-line summaries for notifications without breaking other event kinds.
</objective>

  <name>Task 1: Smarter notification summaries</name>
  <files>packages/core/src/row-projection.ts</files>
  <action>
Inside `eventSummaryOf`, replace the two notification branches:

```ts
if (event.kind === "protocol-notification") { ... }
if (event.kind === "client-notification" || event.kind === "server-notification") { ... }
```

with logic that prefers extracted fields:

1. Compute `notifPayload = notification ?? params`.
2. Extract candidate fields once (use existing helpers `firstString`, `stringField`, `clip`):
   - `state = firstString(notifPayload?.state, notifPayload?.status)`
   - `message = firstString(notifPayload?.message, notifPayload?.text, notifPayload?.detail, notifPayload?.reason)`
   - `notifType = event.actionType ?? stringField(notification, "type") ?? null`
3. For `protocol-notification`:
   - If `state &amp;&amp; notifType` → return `notification ${notifType} ${clip(state)}`.
   - Else if `message &amp;&amp; notifType` → return `notification ${notifType} ${clip(message)}`.
   - Else if `notifType` → return `notification ${notifType} ${summarizeValue(notifPayload)}` (legacy fallback).
   - Else → return `notification ${summarizeValue(notifPayload)}` (legacy fallback).
4. For `client-notification` / `server-notification`:
   - Let `methodLabel = event.method ?? "notification"`.
   - If `message` → return `${methodLabel}: ${clip(message)}`.
   - Else if `state` → return `${methodLabel} ${clip(state)}`.
   - Else → return `${methodLabel} ${summarizeValue(params)}` (legacy fallback).

Do not modify other branches. Keep `capSummary` clipping in callers.

Add a tiny helper inside the file (or inline) only if it shortens the diff; do not export new symbols.
  </action>
