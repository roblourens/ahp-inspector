<objective>
Fix the broken pretty-JSON layout in the event detail pane: nested values are
over-indented and separated by unwanted vertical gaps.

Purpose: react-json-view-lite (2.5.0) renders each object/array's child fields
inside a `<ul class="ahp-json-children">`. That class is mapped in
PrettyJsonView's JSON_STYLES (`childFieldsContainer: "ahp-json-children"`) but
has NO rule in global.css, so the `<ul>` falls back to browser defaults:
`padding-inline-start: 40px`, `margin: 12px 0`, and `list-style: disc`. The 40px
padding stacks on top of the intended per-level `.ahp-json-child { margin-left:
var(--space-4) }`, producing ~56px of indentation per depth plus vertical gaps —
the visible "broken layout" regression. Resetting the container restores clean,
single-level indentation driven solely by `.ahp-json-child`.

Output: A `.ahp-json-children` reset rule in global.css plus a regression test
that fails if the reset is removed.
</objective>

PrettyJsonView (packages/ui/src/components/detail/PrettyJsonView.tsx) maps
react-json-view-lite slots to class names via JSON_STYLES, including:
```typescript
basicChildStyle: "ahp-json-child",
childFieldsContainer: "ahp-json-children",
expandIcon: "ahp-json-expander",
collapseIcon: "ahp-json-expander",
```

Rendered DOM (react-json-view-lite 2.5.0): each property row is a
`<div class="ahp-json-child">`, and an object/array's children are wrapped in a
`<ul class="ahp-json-children">`. Indentation is intended to come ONLY from:
```css
.ahp-json-child { margin-left: var(--space-4); }
```
But `.ahp-json-children` has no rule, so the `<ul>` uses browser defaults
(padding-inline-start: 40px; margin: 12px 0; list-style: disc).

Existing CSS-guard test pattern lives at
packages/ui/src/styles/no-hex-in-components.test.ts (reads source files and
asserts on their text).
</interfaces>
</context>

<task name="Reset the JSON child-fields container and add a regression guard">

Add a reset rule for `.ahp-json-children` in
packages/ui/src/styles/global.css (next to the other `.ahp-json-*` rules) that
neutralizes the browser-default `<ul>` styling so indentation comes solely from
`.ahp-json-child`:

```css
.ahp-json-children {
  margin: 0;
  padding: 0;
  list-style: none;
}
```

Then add packages/ui/src/styles/json-tree-indent.test.ts — a regression guard
(modeled on no-hex-in-components.test.ts) that reads global.css and asserts the
`.ahp-json-children` selector exists and resets `margin`, `padding`, and
`list-style` (so a future edit that drops the reset fails CI). Keep the test
token/text-based since jsdom does not compute layout.

Do NOT change PrettyJsonView.tsx, the JSON_STYLES mapping, or any other
component — the only product change is the CSS reset.
</task>
