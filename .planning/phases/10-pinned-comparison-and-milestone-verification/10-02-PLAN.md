<objective>
Add a basic before/after comparison for two pinned reconstructed state points.

Purpose: satisfy COMPARE-02 by showing event/resource metadata and changed top-level paths while preserving COMPARE-03 local-only privacy and avoiding deep diff complexity.

Output: pure top-level comparison helper, comparison UI in the pinned-state panel, confidence warning behavior, tests, and styling.
</objective>

<must_haves>
- Comparison appears only when two pinned points exist.
- Comparison shows both event indexes, event labels, resource kind/URI, and confidence labels.
- Comparison reports changed top-level paths/keys with a display cap and overflow count.
- If either point is partial or unknown, comparison text explicitly says the result may be incomplete.
- Comparison is pure browser-side computation with no server calls, no outbound network, and no persistence.
- No recursive semantic deep diff is introduced in Phase 10.
</must_haves>
