Important Phase 8 behavior:

- `GET /api/state-at?idx=<idx>&logKey=<logKey>` returns metadata-first `resources[]` and `selectedResource: null`.
- Full state is returned only when both `resourceKind` and `resourceUri` are provided.
- `409 log-mismatch` means the active log changed and should be treated as stale-request UI, not app corruption.

Existing detail flow:

- `DetailPanel` reads `selectedIdx`, `logKey`, `rows`, and `detailWidth` from `useAppStore`.
- Event details load through `fetchEvent(idx, signal, logKey)`.
- Detail view already has populated-state header, tabs, copy menu, privacy caption, drawer/rail layout, and abort-on-selection-change pattern.

  <files>packages/ui/src/transport/state-client.ts, packages/ui/src/transport/state-client.test.ts</files>
  <behavior>
    - `fetchStateAt(7, { logKey: "log-A" })` calls `/api/state-at?idx=7&logKey=log-A`.
    - `fetchStateAt(7, { logKey: "log-A", resourceKind: "session", resourceUri: "session://a b" })` URL-encodes `resourceKind` and `resourceUri`.
    - 200 responses parse as `StateAtSuccessResponse` and preserve `resources[]`, `confidence`, `diagnostics`, `intents`, `cache`, and `selectedResource`.
    - 404 returns `null` so callers can render event-not-found state.
    - 409 `log-mismatch` throws an Error whose message includes "active log changed".
    - Non-OK responses throw an Error containing the HTTP status and server `message` when present.
    - A provided `AbortSignal` is passed through RequestInit without adding `signal: undefined`.
  </behavior>
  <action>
    Create `state-client.ts` as a browser-only transport module modeled after `http-client.ts`. Duplicate the minimal response types in UI instead of importing server route types, because boundary tests forbid `@ahp-viewer/server` and Hono imports in `packages/ui/src`. Define `ReplayConfidence`, `StateResourceKind`, metadata, selected resource, diagnostic, intent, cache, success, and error response types. Implement `fetchStateAt(idx, options)` with `URLSearchParams`, exact non-negative idx input, optional `logKey`, optional paired `resourceKind` + `resourceUri`, and conditional RequestInit spread for `signal` to satisfy `exactOptionalPropertyTypes`. Do not add client caching; Phase 8 owns server-side exact-index caching.
  </action>
