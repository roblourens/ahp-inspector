Required behavior from Phase 8 and 09-01:

- Metadata response: `resources[]` contains `{ kind, uri, confidence, baselineEventIdx, lastAppliedEventIdx, baselineFromSeq, lastServerSeq, diagnosticCount }`.
- Metadata response has `selectedResource: null`.
- Selected response requires both `resourceKind` and `resourceUri`.
- Default selection rule: first `complete` resource if present, else first available resource.
- If no resources exist, render an explicit empty state and do not request full state.
