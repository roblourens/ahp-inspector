<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| raw JSON log payload → replay guards | `AhpEvent.raw` is unknown untrusted JSON parsed from logs |
| replay core → generated protocol reducers | Guards and narrow casts convert raw envelopes into canonical reducer input |
| Phase 7 core scope → Phase 8/9 integration | Replay must not create server API, cache lifecycle, UI, screenshot, or docs work |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-07-01-01 | Tampering | `event.raw.params` action envelope extraction | mitigate | Validate raw payloads with local type guards before reducer casts; malformed entries emit `malformed-envelope` and do not mutate state. |
| T-07-01-02 | Tampering | snapshot baseline installation | mitigate | Install only guarded snapshots with known resource kind; ambiguous snapshots emit `unknown-snapshot` and are skipped. |
| T-07-01-03 | Denial of Service | malformed parse-error events | mitigate | Convert `parse-error` events to diagnostics and continue without throwing. |
| T-07-01-04 | Elevation of Privilege | missing baseline reducer application | mitigate | Never synthesize empty root/session/terminal state; actions without baselines emit `missing-baseline`. |
| T-07-01-05 | Tampering | rejected server action envelopes | mitigate | Treat `rejectionReason` envelopes as diagnostic non-mutating events. |
| T-07-01-06 | Information Disclosure | Phase 8/UI scope creep | mitigate | Restrict files to `packages/core/package.json`, `packages/core/src/index.ts`, `packages/core/src/replay.ts`, and `packages/core/src/replay.test.ts`; no server routes, UI, screenshots, or real logs. |
</threat_model>
