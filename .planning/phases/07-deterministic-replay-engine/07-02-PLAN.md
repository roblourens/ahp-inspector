<objective>
Make reducer execution deterministic by applying each reducer under the current event timestamp, capturing generated reducer logs as diagnostics, and diagnosing serverSeq ordering problems.

Output: Event-time reducer wrapper, stability tests, Date.now restoration tests, reducer-log diagnostics, and serverSeq gap/duplicate/out-of-order diagnostics.
</objective>

Reducer methods from generated protocol:
```ts
export function rootReducer(state: RootState, action: RootAction, log?: (msg: string) => void): RootState;

```

Reducer Date.now usage exists in session reducer branches such as:
```ts
summary: { ...state.summary, title: action.title, modifiedAt: Date.now() }
summary: { ...state.summary, model: action.model, modifiedAt: Date.now() }
summary: { ...state.summary, modifiedAt: Date.now() }
```

Phase 7 Date.now rule:
```ts
const original = Date.now;
Date.now = () => eventTs;
try {
  return fn();
} finally {
  Date.now = original;
}
```
No `await` is allowed inside the patched scope.
