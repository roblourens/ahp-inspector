<interfaces>
Reconnect result shapes:
```ts
export const enum ReconnectResultType {
  Replay = "replay",
  Snapshot = "snapshot",
}

export interface ReconnectReplayResult {
  type: ReconnectResultType.Replay;
  actions: ActionEnvelope[];
  missing: URI[];
}

export interface ReconnectSnapshotResult {
  type: ReconnectResultType.Snapshot;
  snapshots: Snapshot[];
}

export type ReconnectResult = ReconnectReplayResult | ReconnectSnapshotResult;
```

Client dispatchAction shape:
```ts
export interface DispatchActionParams {
  clientSeq: number;
  action: StateAction;
}
```

Action origin linkage:
```ts
export interface ActionOrigin {
  clientId: string;
  clientSeq: number;
}

export interface ActionEnvelope {
  readonly action: StateAction;
  readonly serverSeq: number;
  readonly origin: ActionOrigin | undefined;
  readonly rejectionReason?: string;
}
```

```ts
export interface ReplayClientIntent {
  eventIdx: number;
  ts: number;
  clientSeq: number | null;
  actionType: string | null;
  resource: ReplayResourceKey | null;
  acceptedByServerSeq?: number;
  ignored: true;
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| reconnect raw response → replay application | Reconnect result payloads are untrusted raw JSON and may contain malformed snapshots or action arrays |
| client notification → canonical state | Client dispatchAction is intent only and must not mutate reconstructed server-authoritative state |
| client intent → server envelope linkage | Matching by `origin.clientSeq` is diagnostic linkage only; mutation comes from server envelope |
| Phase 7 core → later server/UI phases | Complete replay behavior must not add Phase 8-10 integration files |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-07-03-01 | Tampering | reconnect replay `actions[]` | mitigate | Guard every embedded action envelope; malformed entries emit `malformed-envelope` and later valid entries still process. |
| T-07-03-02 | Tampering | reconnect snapshot replacement | mitigate | Install only guarded snapshots with known resource kind; ambiguous snapshots emit diagnostics and are skipped. |
| T-07-03-03 | Repudiation | reconnect `missing[]` | mitigate | Emit `reconnect-missing-resource` diagnostics with event index and URI. |
| T-07-03-04 | Elevation of Privilege | client dispatchAction intent | mitigate | Record intent and `ignored-client-intent` diagnostic, but never call reducers from c2s dispatchAction. |
| T-07-03-05 | Tampering | client intent accepted linkage | mitigate | Link `acceptedByServerSeq` only from later server `ActionEnvelope.origin.clientSeq`; server envelope remains sole mutation path. |
| T-07-03-06 | Tampering | Date.now in reconnect embedded actions | mitigate | Apply embedded envelopes through the existing synchronous event-time wrapper using reconnect response `AhpEvent.ts`. |
| T-07-03-07 | Information Disclosure | Phase 8/UI scope creep | mitigate | Final validation rejects modifications outside pure core files and excludes server routes, AppState cache, API, UI, screenshots, Playwright, and user guide work. |
</threat_model>
