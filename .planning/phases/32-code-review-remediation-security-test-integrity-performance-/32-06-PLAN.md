# Plan 32-06 — Robustness & correctness

**Phase:** 32 — Code review remediation
**Wave:** 2
**Requirement:** CR-ROBUST

## Objective

Three smaller correctness/robustness fixes:
- the correlator/event-store `pendingResponses` map grows unbounded during long
  live-tail sessions when requests never get a matching response;
- `replay.ts` monkeypatches `Date.now`, which is fragile and order-dependent;
- `turnShort` uses a naive `turn.slice(-6)` while `sessionShort` already has
  smart formatting — turn IDs should get the same treatment.

## Tasks

1. **Bound `pendingResponses`**: cap the outstanding-request map (size-bounded
   eviction of the oldest unmatched request) so a long session cannot leak
   memory; preserve correct pairing for in-flight requests within the bound.

2. **Injectable clock in `replay.ts`**: replace the `Date.now` monkeypatch with
   an injected `now()`/clock parameter (default `Date.now`) so tests pass a fake
   clock instead of mutating the global.

3. **Smart `turnShort`** (`packages/core/src/row-projection.ts`): mirror
   `formatSessionShort` so turn IDs render a clean short form across the TURN
   column, group headers, and sticky bar (hash-like real IDs already look fine;
   this removes the fragility for any prefixed/suffixed form).

## Verification

- New test: pending-response map stays at/below the cap under a flood of
  unmatched requests.
- `replay.test.ts` uses the injected clock; no global `Date.now` mutation.
- New/updated `row-projection` test covers `turnShort` formatting parity with
  `sessionShort`.
- `pnpm vitest run` green.
