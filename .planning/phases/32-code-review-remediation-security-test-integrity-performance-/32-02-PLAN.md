# Plan 32-02 — Test integrity (style guard)

**Phase:** 32 — Code review remediation
**Wave:** 1
**Requirement:** CR-TEST

## Objective

`packages/ui/src/styles/no-hex-in-components.test.ts` resolves its source root
from `new URL("../", import.meta.url).pathname`, which points at a directory
that `readdirSync` cannot walk as intended, so `walk()` returns `[]` and the
guard passes vacuously. As a result it never caught the raw `rgb(...)` literal
in `TimelineList.tsx`. Make the guard resolve the real source tree and fail
loudly, then fix the literal it should have caught.

## Tasks

1. **Fix path resolution**: use `fileURLToPath` to derive the absolute source
   directory and assert the walk actually found component files (e.g.
   `expect(files.length).toBeGreaterThan(20)`), so an empty walk can never
   silently pass again.

2. **Confirm it now catches the real literal**: with the fix in place, the test
   should flag the `rgb(...)` literal in `TimelineList.tsx`.

3. **Fix the offending literal** (`packages/ui/src/components/timeline/TimelineList.tsx`):
   replace the raw `boxShadow: "0 6px 18px rgb(0 0 0 / 0.16)"` with the existing
   semantic shadow token (or add one if none fits), matching how the rest of the
   file references tokens.

## Verification

- Temporarily planting a `#abc`/`rgb()` literal in a component makes the guard
  fail (proves it is no longer vacuous); remove the plant.
- The `TimelineList` literal is gone; `pnpm vitest run` green; the shadow renders
  unchanged (same computed value via the token).
