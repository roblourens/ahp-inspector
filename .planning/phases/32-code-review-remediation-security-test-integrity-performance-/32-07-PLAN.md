# Plan 32-07 — DevX hygiene

**Phase:** 32 — Code review remediation
**Wave:** 1
**Requirement:** CR-DEVX

## Objective

A stray `.claude/worktrees/` tree (untracked, not ignored) pollutes `git
status` and `grep`, and its nested `biome.json` breaks `pnpm lint` locally.
Make the repo ignore it and keep lint scoped to real sources.

## Tasks

1. **Gitignore**: add `.claude/` to `.gitignore` so worktrees and tool state do
   not show up as untracked or get accidentally committed.

2. **Scope lint**: ensure `pnpm lint` (Biome) does not descend into `.claude/`
   (and other worktrees), e.g. via the root `biome.json` ignore globs, so a
   nested config cannot hijack or break the run.

## Verification

- `git status` no longer lists `.claude/`.
- `pnpm lint` runs clean end-to-end (does not error on nested worktree config).
- No real source files are excluded from lint by the new ignore globs.
