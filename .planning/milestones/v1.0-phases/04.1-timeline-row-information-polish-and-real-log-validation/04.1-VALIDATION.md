# Phase 04.1 — Validation Strategy

> Per-phase validation contract for row information polish, correlation highlighting, detail defaults, and privacy-safe real-log validation.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| Framework | Existing Vitest + jsdom + Testing Library React |
| Config | Root `vitest.config.ts`; UI package `packages/ui/vitest.config.ts` |
| Quick UI run | `pnpm -F @ahp-viewer/ui test` |
| Full gate | `pnpm test && pnpm -F @ahp-viewer/ui build && pnpm typecheck && pnpm lint` |
| Runtime policy | Run focused verification after each plan and the full gate at phase end |

---

## Sampling Rate

- After parser/core changes: run targeted parser/core/server/store tests before UI work proceeds.
- After row UI changes: run EventRow, TimelineList, TimelineRegion, and detail tests.
- Before UAT/screenshots: run fixture scrub checks and privacy grep checks.
- Before completion: run Phase 4 vertical-slice regression and full gate.
