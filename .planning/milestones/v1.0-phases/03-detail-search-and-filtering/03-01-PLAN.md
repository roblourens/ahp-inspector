<objective>
Wave 1 — server backend: add the two HTTP endpoints that cannot be satisfied
from existing SSE state, and the search haystack that powers them.

`GET /api/log/event/:idx` returns the full canonical `AhpEvent` (including
`raw`) plus correlator metadata — the data Detail UI needs that was
intentionally excluded from SSE projections to prevent 10–100× transfer bloat.

`GET /api/log/search?q=...` scans a per-event lowercased haystack built
incrementally at append time — the only safe way to full-payload search without
shipping all raw JSON to the browser.

Purpose: Plans 03-03 (Detail UI) and 03-04 (Search client) both call these
endpoints. They can be built in parallel with Plan 03-02 (store + selectors)
because this plan only touches `packages/server/src`.

Output: `search-index.ts`, `detail-routes.ts`, `search-routes.ts`, updates to
`app-state.ts` and `log-server.ts`, and integration tests for both routes.
</objective>

Create `packages/server/src/search-index.ts`:

```ts
import type { AhpEvent } from "@ahp-inspector/shared";

/**
 * Per-event lowercased haystack for server-side substring search (SEARCH-01).
 * Grows in lock-step with EventStore — index[i] is the haystack for event i.
 * Pattern from 03-RESEARCH §Pattern 2.
 */
export class SearchIndex {
  readonly #haystack: string[] = [];

  get size(): number {
    return this.#haystack.length;
  }

  append(ev: AhpEvent): void {
    const idStr = ev.id !== null ? String(ev.id) : null;
    let rawStr = "";
    try {
      rawStr = JSON.stringify(ev.raw) ?? "";
    } catch {
      rawStr = "";
    }
    const entry = [
      ev.method,
      ev.actionType,
      ev.sessionId,
      ev.turnId,
      idStr,
      rawStr,
    ]
      .filter(Boolean)
      .join(" ")
      .toLowerCase();
    this.#haystack.push(entry);
  }

  scan(
    q: string,
    limit: number,
  ): { matches: number[]; truncated: boolean } {
    const matches: number[] = [];
    const matchAll = q === "";
    for (let i = 0; i < this.#haystack.length && matches.length < limit; i++) {
      if (matchAll || this.#haystack[i]!.includes(q)) {
        matches.push(i);
      }
    }
    const truncated = matches.length === limit && this.#haystack.length > limit;
    return { matches, truncated };
  }
}
```

```ts
import type { Hono } from "hono";
import type { AhpEvent } from "@ahp-inspector/shared";
import type { Status } from "@ahp-inspector/core";
import type { AppState } from "./app-state.js";

export type DetailResponse = {
  event: AhpEvent;
  pair: AhpEvent | null;
  latencyMs: number | null;
  status: Status;
  pairIdx: number | null;
};

export function registerDetailRoutes(app: Hono, appState: AppState): void {
  app.get("/api/log/event/:idx", (c) => {
    const raw = c.req.param("idx");
    const idx = parseInt(raw, 10);
    if (!Number.isFinite(idx) || idx < 0) {
      return c.json({ error: "invalid idx" }, 400);
    }
    const event = appState.eventAt(idx);
    if (!event) {
      return c.json({ error: "not found" }, 404);
    }
    // Correlator metadata (correlator is private; expose via AppState).
    const correlatorData = appState.correlatorDataFor(idx);
    const pairIdx = correlatorData.pairIdx;
    const pair = pairIdx !== null ? appState.eventAt(pairIdx) ?? null : null;
    const response: DetailResponse = {
      event,
      pair,
      latencyMs: correlatorData.latencyMs,
      status: correlatorData.status,
      pairIdx,
    };
    return c.json(response, 200);
  });
}
```

```ts
import type { Hono } from "hono";
import type { AppState } from "./app-state.js";

const MAX_QUERY_LEN = 256;
const MAX_RESULTS = 5000;

export function registerSearchRoutes(app: Hono, appState: AppState): void {
  app.get("/api/log/search", (c) => {
    const rawQ = c.req.query("q") ?? "";
    const q = rawQ.toLowerCase().slice(0, MAX_QUERY_LEN);
    const rawLimit = parseInt(c.req.query("limit") ?? String(MAX_RESULTS), 10);
    const limit = Math.min(
      Number.isFinite(rawLimit) && rawLimit > 0 ? rawLimit : MAX_RESULTS,
      MAX_RESULTS,
    );
    const { matches, truncated } = appState.searchIndex.scan(q, limit);
    return c.json({ matches, total: matches.length, truncated });
  });
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP request → Hono route | `idx` param and `q` query param are untrusted user input |
| AhpEvent.raw → JSON response | Full payload passes through — user data; only server-generated fields need sanitization |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01-01 | DoS (ReDoS) | GET /api/log/search | mitigate | Substring `String.prototype.includes` only — no regex from user input; query capped at 256 chars before scan |
| T-03-01-02 | DoS (unbounded result) | GET /api/log/search | mitigate | `limit` param hard-capped at 5000 server-side regardless of client request |
| T-03-01-03 | Tampering | GET /api/log/event/:idx | mitigate | `idx` validated with `parseInt` + `Number.isFinite` + bounds check; returns 400/404 before any store access |
| T-03-01-04 | Info Disclosure (path leak) | DetailResponse | mitigate | `AhpEvent` has no `path` field; `LogMeta` is not included in response; test asserts absolute fixture path absent from response JSON |
| T-03-01-05 | DoS (listener leak) | SearchIndex append | accept | SearchIndex.append is O(1) per event; no async, no listener; memory bounded by EventStore.size × ~1KB average haystack entry |
</threat_model>
